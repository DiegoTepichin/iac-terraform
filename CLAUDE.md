# CLAUDE.md

Operating context for coding agents working in this repository. The human guide is [CONTRIBUTING.md](CONTRIBUTING.md); this file covers only what an agent must know.

## What this is

Terraform for AWS (`us-east-1`): a VPC with an Application Load Balancer in public subnets and an Auto Scaling Group (Ubuntu + Nginx) in private subnets, deployed to three isolated environments. Remote state in S3 with locking in DynamoDB.

```text
backend/               bootstrap of the S3 bucket + DynamoDB table (LOCAL state, not versioned)
environments/<env>/    root modules dev | staging | prod (remote state per environment)
modules/networking/    VPC, subnets, IGW, optional NAT, default SG with no rules
modules/web_app/       ALB, target group, launch template, ASG, scaling policy, SGs, IAM role (SSM), user_data in templates/
```

The state bucket name lives in `environments/<env>/backend.hcl` (git-ignored, generated by `make backend-config`).

## Commands

```bash
make ci                    # fmt-check + validate-all + lint + test + security-scan
make test                  # terraform test with mock_provider (no AWS credentials)
make validate-all          # init -backend=false + validate in the 4 root modules
make plan ENV=dev          # needs AWS credentials and an initialized backend
```

## Rules

- **Never** run `apply`, `destroy`, `backend-init`, `backend-destroy`, `force-unlock` or `state rm/mv` without explicit user approval.
- **Never** delete or edit `*.tfstate` (especially `backend/terraform.tfstate`, which is unrecoverable) or the `.terraform.lock.hcl` of root modules.
- **Never** read or print `terraform.tfvars` or `backend.hcl`; use the variable defaults and `environments/backend.hcl.example`.
- Modules declare no `provider` block; common tags go in the root module's `default_tags`.
- Structural changes to one environment (`main.tf`, `providers.tf`, `outputs.tf`) are applied to all three.
- Every constrained variable gets a `validation` and an `expect_failures` test in `modules/*/tests/`.
- Checkov exceptions: inline `# checkov:skip=<ID>:<reason>`, never global.
- Conventional Commits (`feat|fix|refactor|test|ci|build|docs|chore`), one logical change per commit.
- `.terraform` is a symlink to `.terraform.nosync` (iCloud exclusion); do not turn it into a directory.
